# Week 4 Lab: Weekly Sales Monitor

## Task

Create `lab04_sales_monitor.py`. Ask for a daily target and seven daily sales values. Use a loop to calculate the weekly total, average and number of days meeting the target. Re-prompt when a sale is negative.

## Acceptance Checks

1. Exactly seven valid values contribute to the total.
2. The average equals total divided by seven.
3. The target count includes a day that equals the target.
4. Test seven zero values and a mix of values.

## Stretch Task

Add the highest sale and its day number without using a list.
